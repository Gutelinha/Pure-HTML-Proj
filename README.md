# 📄 Pure-HTML-Proj

Este é um projeto desenvolvido como parte do curso da [OneBitCode](https://onebitcode.com). O objetivo deste projeto é praticar e consolidar os conhecimentos em **HTML puro**, abordando conceitos como estrutura básica de páginas web, semântica, formulários, listas, links e imagens.

## 🚀 Tecnologias Utilizadas

- HTML5

## 🧠 O que eu aprendi

- Estrutura básica de um documento HTML
- Uso correto de tags semânticas (`<header>`, `<main>`, `<footer>`, etc.)
- Como criar links, listas, formulários e incorporar imagens
- Boas práticas de indentação e organização
